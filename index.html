0 · Conventions

0.1Structure of a complete answer

The course admits no universally optimal WSN protocol; a design claim is therefore only complete when its mechanism, its benefit, the displaced cost and its validity conditions are stated:

claim := ⟨mechanism, quantity improved, quantity degraded, operating conditions (traffic λ, topology, link quality p)⟩

Incomplete: “ContikiMAC is energy efficient.” Complete: “ContikiMAC reduces the receiver’s idle duty cycle to T_c / T_w by having the sender retransmit the full data frame until acknowledged; the cost is transferred to sender airtime, with expected rendezvous latency T_w / 2 per hop. The trade-off is favourable for sparse unicast (small λ) and unfavourable for broadcast, which must span a full T_w.”

For experimental answers, report configuration (platform, radio medium, RDC/MAC driver, traffic interval, duration), measurement (counts, PRR, Energest ticks) and interpretation. A screenshot is not a result; an interpreted measurement is.

1 · WSN & mote hardware

A sensor network is not a conventional network at reduced scale; it is computation coupled to a physical environment under severe resource constraints.

1.1Definitions and reference architecture

Definition 1.1 · Wireless sensor network

A set of spatially distributed embedded nodes (motes) that sense, process and communicate wirelessly, together with one or more sinks (gateways, border routers) that collect data and interconnect the network with users or other networks. Traffic is predominantly small, periodic or event-driven, and the design is energy-constrained. A WSN is measurement infrastructure, not a population of general-purpose mobile devices.

A WSN may form part of an IoT or CPS architecture, or operate standalone. The gateway is the translation point between constrained wireless networking and conventional computing infrastructure.

2 · Radio & PHY

A wireless link is a time-varying stochastic channel; routing, scheduling and energy models that assume a deterministic link are invalid T1.

2.1Power units, link budget, SNR

Definition 2.1 · Logarithmic power

P_dBm = 10 log₁₀(P / 1 mW) is an absolute level. A quantity in dB is a dimensionless ratio (gain or loss). Hence dBm ± dB = dBm, and dBm − dBm = dB.

+3 dB ≈ ×2, +10 dB = ×10, −10 dB = ÷10. −80 dBm denotes ten times more power than −90 dBm.

P_r = P_t + G_t + G_r − PL(d) − L_s(2.1)

Example (slide 10): P_t = 0 dBm, G_t = G_r = 0 dB, PL = 75 dB, L_s = 2 dB ⇒ P_r = −77 dBm.

γ_dB = P_r − N₀(2.2)
  • Signal −80 dBm, noise −100 dBm ⇒ γ = 20 dB; signal −80 dBm, noise −82 dBm ⇒ γ = 2 dB. Equal RSSI does not imply equal link quality.
  • Receiver sensitivity is the input level at which a specified error-rate target is met. It is not a threshold separating perfect from impossible reception: frame success decays continuously with γ T5. Bench B1 makes the shape of this decay explicit.

2.2Propagation models

EffectScalePhysical cause
Path lossMean trend in distanceSpreading, absorption, reflection, diffraction, scattering, penetration, polarisation
ShadowingLarge-scale, slow deviation from the trendObstacles: walls, metal, bodies, vegetation, machinery
FadingSmall-scale, faster variationMultipath superposition of copies with distinct amplitude, phase, delay
PL_FS(d) = 20 log₁₀(4πd / λ), λ = c / f(2.3)

At 2.4 GHz, λ = 0.125 m ⇒ PL_FS(1 m) = 40.0 dB, PL_FS(10 m) = 60.0 dB; free space adds 20 dB per decade.

PL(d) = PL(d₀) + 10 n log₁₀(d / d₀) + X_σ, X_σ ~ 𝒩(0, σ²)(2.4)

Log-distance model with log-normal shadowing. n = 2 in free space and larger indoors (example: PL(1 m) = 40 dB, n = 3 ⇒ PL(10 m) = 70 dB, 10 dB above free space). Larger σ means greater variability at a fixed distance; both n and σ are estimated by measurement.

  • Multipath: components in phase add constructively, in antiphase destructively. With λ = 12.5 cm, displacements of a few centimetres alter received power.
  • Slow vs fast fading: channel coherence time long vs short relative to a frame. Static nodes fade because the environment moves.
  • Flat vs frequency-selective: whether the signal bandwidth is narrower than the channel coherence bandwidth (equivalently, delay spread small relative to symbol time).
P_r(d, t) = P_r(d₀) − 10 n log₁₀(d / d₀) − X_σ + F(t)(2.5)

Received power is a random variable conditioned on distance, not a function of it. Link selection must use measured delivery T1.

2.3Link-quality estimators

Definition 2.2 · Packet reception ratio

For a directed link and an observation window of N_tx sequence-numbered transmissions, PRR = N_rx / N_tx. PRR is an estimator of the per-frame success probability p; with independent trials its standard error is √(p(1−p)/N_tx), so short windows are noisy (Bench B2).

Frame-error model used in Bench B1. For the 2.4 GHz O-QPSK DSSS PHY, the IEEE 802.15.4 standard (and the ns-3 LR-WPAN error model) gives the AWGN bit error rate as BER(γ) = (8/15)·(1/16)·Σ_{k=2}^{16} (−1)^k C(16,k) e^{20γ(1/k − 1)} with γ linear. For a frame of L bytes and independent bit errors, p(γ) = (1 − BER)^{8L}. Combining with Eq. 2.4, the per-link success probability becomes a random variable whose spread is governed by σ; this is the origin of the transitional region (Zuñiga & Krishnamachari, 2004).

2.4Transitional region, hysteresis, asymmetry

Definition 2.3 · Link regions
  • Connected: high, stable PRR; few retransmissions.
  • Transitional: intermediate and highly variable PRR, bursty losses, asymmetry.
  • Disconnected: PRR ≈ 0; unstable neighbour discovery.

Transitional links are costlier than clearly bad ones: a neighbour appears and disappears, broadcasts succeed while ACKs fail, routing repeatedly adopts and discards the link, and retransmissions consume energy. The shortest geographic link is not the minimum-energy link.

Definition 2.4 · Hysteresis

Neighbour admission with two thresholds θadd > θdrop (slide 40: add if PRR > 0.8, retain until PRR < 0.5). A single threshold θ causes oscillation whenever the estimate fluctuates around θ; the band [θdrop, θadd] absorbs estimator noise at the cost of slower reaction.

B2 · PRR estimation window and hysteresisDefs. 2.2, 2.4

A link with slowly varying true success probability p(t) (AR(1) process around μ) is sampled in windows of W frames. Compare neighbour-table decisions with one threshold θ and with hysteresis 0.8 / 0.5. Increase W to reduce estimator variance; observe the reaction delay this introduces.

3000 frames per realisation

Asymmetry: e.g. PRR(A→B) = 0.95, PRR(B→A) = 0.40, caused by unequal transmit power, receiver sensitivity, antenna orientation, local noise floor, interference near one receiver, or transient fading. For an exchange requiring an acknowledgement:

P_success = PRR_fwd × PRR_rev 0.90 × 0.50 = 0.45(2.6)

A node may receive a parent’s advertisements reliably, select it, and then fail in the reverse direction required by the protocol.

2.5IEEE 802.15.4 PHY

IEEE 802.15.4 specifies the PHY and MAC sublayer for low-rate, energy-constrained wireless networks. 802.15.4 ≠ Zigbee T7: Zigbee adds network, application-support and profile layers; 6LoWPAN, WirelessHART and ISA100.11a also operate over 802.15.4.

  • DSSS: spreading over 32 chips yields processing gain, aiding synchronisation and narrowband-interference rejection; it does not confer immunity.
  • O-QPSK: the quadrature component is offset by half a chip, limiting phase transitions to ±90°. The receiver inverts the chain (waveform → chips → symbols → bits) when it can synchronise.
  • Throughput is strictly below 250 kb/s: PHY/MAC headers, addressing, FCS, security, ACKs, backoff and retransmissions.
  • Energy Detection (ED) measures in-channel energy without identifying source or decodability. Clear Channel Assessment (CCA) reports whether the channel appears busy; it supports CSMA/CA but cannot prevent all collisions because it samples the channel at the transmitter T4 (§4.3).
  • 2.4 GHz coexistence: IEEE 802.11, Bluetooth, other 802.15.4 networks, microwave ovens, industrial equipment ⇒ loss, retransmission, energy, delay, route churn and apparent asymmetry.

3 · Energy

A WSN is useful only if it delivers its sensing function sustainably under an explicit energy budget: sustainable service = required sensing + required communication + acceptable lifetime. Energy constrains application behaviour (sampling rate, in-network processing), communication (wake schedule, retransmission limits, control rate) and network behaviour (forwarder selection, load balance, repair).

4.1Function of the MAC sublayer

  • Node: sensor, actuator, router or sink. Link: direct single-hop relation. Path: sequence of links. Frame = MAC header + packet + trailer; packet = IP header + transport data; payload = application data. The MAC schedules and protects link-layer frames on a shared local medium.
  • The MAC decides channel access (transmit, defer, back off) and, in WSNs, radio wake-up (listen, transmit, sleep). Conventional MAC objectives (collision avoidance, fairness) are augmented by minimisation of idle listening and unnecessary wake-ups.

4.3Hidden and exposed terminals

Definition 4.1 · Hidden terminal

Transmitters A and C with a common receiver B such that A and C are outside each other’s carrier-sense range while both are within interference range of B. Both sense an idle channel and transmit; the frames collide at B.

Definition 4.2 · Exposed terminal

Transmitter C defers because it senses an ongoing transmission B → A, although C → D would not have corrupted reception at A (and B → A would not have corrupted reception at D). The cost is lost spatial reuse.

RTS/CTS

RTS → CTS → DATA → ACK. Nodes that decode the CTS defer, protecting the receiver against hidden senders. Its limited applicability to sensor networks follows from four facts:

  1. No IEEE 802.15.4 release defines RTS/CTS; Zigbee, Wi-SUN and 6LoWPAN stacks inherit none.
  2. Control overhead is disproportionate for small frames: experimentally, RTS/CTS improved bandwidth efficiency over basic access only with ≈ 5 concatenated frames (Barroca et al., 2020).
  3. Broadcast traffic (floods, beacons, routing updates, time synchronisation) has no single receiver to issue a CTS.
  4. Interference range exceeds decoding range: a node unable to decode the CTS may still corrupt the data frame.

Further, sleeping nodes miss RTS/CTS exchanges, and RTS/CTS aggravates the exposed-terminal problem by silencing additional neighbours.

4.4Rendezvous and low-power listening

Definition 4.3 · Low-power listening (LPL)

The receiver samples the channel for T_c once per wake-up interval T_w, returning to sleep if no activity is detected. Its idle duty cycle is D_idle ≈ T_c / T_w (5 ms per 500 ms ⇒ 1 %). Rendezvous requires the sender’s wake-up signal to overlap at least one channel check; with preamble sampling the preamble must span T_w plus a guard.

4.5Sender-initiated protocols: B-MAC, X-MAC, ContikiMAC

B-MAC

  • Receiver: wake → CCA → sleep if idle; if a preamble is detected, remain awake until the data frame. No global synchronisation; duty cycle set by T_w.
  • Sender: T_TX ≈ T_preamble + T_data ≥ T_w + T_data, since it cannot know when the receiver woke. Neighbours that wake during the preamble also remain awake (network-wide overhearing); the preamble occupies the channel; hidden terminals persist.

The B-MAC preamble carries no data; the data frame follows the preamble.

X-MAC

  • A train of short addressed strobes separated by gaps in which the sender listens. The destination replies with an early ACK; the sender stops and transmits data. Expected strobing time ≈ T_w / 2.
  • Non-destinations decode one strobe and return to sleep (bounded overhearing).
  • Limitations: strobes and early ACKs can collide; hidden terminals persist; broadcast cannot terminate on a single early ACK.

ContikiMAC

  • The sender repeats the complete data frame; the first copy received in full delivers the data. Efficiency depends on frame length, T_w, inter-frame spacing and ACK reliability.
  • Two successive CCAs detect a frame train while rejecting short noise; fast sleep returns the receiver to sleep on irrelevant or invalid activity.
  • Termination by an ACK that confirms data delivery, not merely wake-up.
  • Phase lock: having learned a neighbour’s wake-up phase, the sender begins shortly before it (plus a guard), reducing expected transmission from T_w / 2 to approximately the guard plus one frame.

ContikiMAC is not X-MAC: it repeats data frames rather than strobes, and its terminating ACK confirms delivery.

Broadcast under asynchronous duty cycling is costly: no single ACK terminates it, and neighbours wake at independent phases, so the sender must repeat for a full T_w.

4.6Receiver-initiated protocols: RI-MAC, A-MAC

The receiver wakes and announces availability with a beacon (RI-MAC) or probe (A-MAC); a sender with pending data listens and responds. No long sender preamble is needed and the receiver controls availability. The sender may listen for up to T_w, and several senders may respond to one beacon: contention moves to the instant after the beacon. A-MAC probes may carry receiver identity, timing and link-layer state, separating “receiver awake” from contention resolution.

5.2TDMA terminology

Definition 5.1 · Timeslot, slotframe, cell
  • Timeslot: the elementary time unit; one opportunity to transmit, receive, acknowledge, contend or sleep.
  • Slotframe of length S: a periodically repeating sequence of timeslots. Slot offset ∈ {0, …, S−1}: position within it.
  • Cell: a (slotOffset, channelOffset) pair assigned to an operation; a communication opportunity, not a packet.
  • Dedicated cell: reserved for one transmitter–receiver pair. Shared cell: usable by several nodes, which contend within it.
  • Dedicated cells provide low collision probability, predictable service and no backoff; they are wasted when the queue is empty and may become invalid after topology change.
  • Shared cells provide flexibility (joining, Enhanced Beacons, routing control, negotiation, bursts) and reintroduce collisions, backoff and retries.
  • Spatial and frequency reuse: non-conflicting links may share a timeslot, and multiple channels multiply reuse. Over-conservative schedules waste capacity.

TDMA does not restrict the network to one transmitter per slot. The objective is to separate conflicts, not to silence the network.

5.3Timeslot structure, guard time, energy and delay

Timeslot constants are the standard defaults, not slide content. They make the guard-time argument quantitative: a drift of ±40 ppm accumulates 80 µs of relative error per second, so ±1100 µs tolerates ≈ 13 s without resynchronisation.

Definition 5.2 · Guard time

The interval a receiver listens around the expected frame arrival to tolerate relative clock error. Error grows with time since last synchronisation; a longer guard increases reliability and listening energy, while more frequent synchronisation increases control traffic. Scheduled MAC converts timing error into energy cost T2.

  • Duty cycle: first approximation active slots / S (10-slot frame, 2 TX + 1 RX ⇒ 30 %); refine with actual TX/RX/listen durations within each slot.
  • Waiting delay: one cell per slotframe yields one service opportunity per frame; for uniform arrivals the mean wait is half the inter-opportunity interval. Additional cells reduce delay at a resource and energy cost. Lower contention does not imply lower latency.
  • Cell ordering: A→B, B→C, C→D in increasing slot offset pipelines a packet through the path in one slotframe; reverse order costs one slotframe per hop.

5.4The scheduling problem

Assign time–frequency resources to transmissions such that conflicting transmissions are separated and traffic demand is met. Inputs: topology, link quality, interference, demand, deadlines, energy. Output: cells.

Definition 5.3 · Communication and conflict graphs

The communication graph G = (V, E) has nodes as vertices and usable links as edges. The conflict graph Gc has transmissions (directed links) as vertices and an edge between two transmissions that cannot share a resource. Conflict sources: shared receiver, shared transmitter, half-duplex operation, interference, ACK overlap. Gc depends on the interference model; an incorrect model yields an incorrect schedule T6.

Graph colouring: assign colours (slots or cells) so that adjacent conflict-graph vertices differ. Fewer colours ⇒ shorter slotframes, lower delay, more reuse. Minimum colouring is NP-hard for general graphs; heuristics are used. Granularity: node colouring (simple, conservative), link colouring (accurate for directed transmissions), two-hop colouring (suppresses hidden terminals, may forbid safe reuse), time–frequency colouring (adds channels). Model fidelity increases problem size.

5.6TSCH

Definition 5.4 · Time-Slotted Channel Hopping

An IEEE 802.15.4 MAC mode (introduced in 802.15.4e) combining time synchronisation, scheduled cells, channel hopping, ACKs and link-layer retransmission. TSCH executes a schedule; it does not prescribe how the schedule is computed T5.

Definition 5.5 · Absolute slot number and channel mapping

ASN counts timeslots since network formation (incremented each slot; used for timing, channel selection, security nonces and slotframe position). With hopping sequence F of length N_c:

channel(ASN, chOff) = F[(ASN + chOff) mod N_c](5.1)

A cell at slot offset s recurs at ASN = k·S + s. A logical cell is therefore stable while its physical channel rotates; a channel offset is not an IEEE 802.15.4 channel number T7.

Result 5.1 · Channels visited by one cell

Successive occurrences advance the index by S mod N_c, so a cell visits exactly N_c / gcd(S, N_c) distinct channels. If S is a multiple of N_c, the cell never hops. Slotframe lengths are therefore chosen coprime to N_c (e.g. S = 101 with N_c = 16).

5.9Feasibility beyond conflict freedom

Definition 5.6 · Utilisation and stability

For a forwarder with aggregate arrival rate λ (packets per slotframe) and c cells per slotframe each succeeding with probability p, the service rate is μ = c·p and the utilisation ρ = λ / μ. The queue is stable only if ρ < 1; for ρ ≥ 1 it grows without bound. Allocated-cell utilisation (fraction of cells carrying packets) that is too low wastes wake-ups; too high leaves no headroom for bursts, retries, control and route changes.

6 · Naming, addressing & 6LoWPAN

Structure of the week: what (name) → where (address) → how to reach (route) → how to fit IPv6 into 127-byte frames (6LoWPAN). Slide numbers refer to the original lecture numbering (1–60).

6.1Names, addresses, routes

Definition 6.1
  • Name: identifies what the application requires (resource, service, data item, event, stream), e.g. /sensors/temperature.
  • Address: identifies a network endpoint or attachment point for delivery, e.g. 2001:db8:1::25.
  • Route: the sequence of forwarding decisions toward an address, e.g. A → parent → relay → border router.

Each may change independently of the others T7. A link-layer address must not serve as a stable application identity, and a URI path is not a routing path.

Identifier stability (lifetime over which an identifier remains bound to the same referent): application names such as /building3/room301/temperature are potentially stable; 802.15.4 short addresses, IPv6 addresses, RPL parents, gateways and next hops are potentially changing. Applications should bind to stable names and resolve them to current endpoints.

IPv6 notation: 128 bits as eight 16-bit hexadecimal groups; leading zeros omitted; one run of zero groups written ::. /64 splits prefix and interface identifier (IID). fe80::/64 link-local; ff02::1 all-nodes, ff02::2 all-routers (link scope); 2001:db8::/32 documentation prefix.

6.3Rationale and functions of 6LoWPAN

  • Header mismatch: IPv6 (40 B) + UDP (8 B) = 48 B before data; the 802.15.4 PSDU is ≤ 127 B including MAC header and FCS.
  • MTU mismatch: IPv6 requires every link to carry 1280-byte packets (RFC 8200 minimum MTU); the adaptation layer must emulate this with fragmentation and reassembly.
  • Frame budget (RFC 4944): 127 − 25 (worst-case MAC overhead) = 102; − 21 (AES-CCM-128 auxiliary header and MIC) = 81 B for IPv6; − 48 = 33 B for data. The lecture uses an effective capacity M ≈ 80 B.
Definition 6.2 · 6LoWPAN

IPv6 over Low-Power Wireless Personal Area Networks: an adaptation layer between IPv6 and the IEEE 802.15.4 MAC that represents IPv6 packets efficiently on the constrained link. Applications retain the IPv6 model; a border router can restore standard IPv6.

6LoWPAN is not a replacement for IPv6, not a routing protocol, not a permanent shortening of 128-bit addresses, not an application protocol, and not a guarantee that every packet fits in one frame.

6.5Fragmentation

A datagram exceeding M is split into fragments, each carried in its own frame with a fragment header. The receiver buffers fragments and delivers the datagram only when all have arrived; the application is unaware of fragmentation. There is no per-fragment recovery: after the reassembly timeout (up to 60 s) the buffer is discarded and the whole datagram must be resent. This is link-level 6LoWPAN fragmentation, distinct from the IPv6 end-to-end fragment header.

Define timeslot, slotframe and slot offset.
Timeslot = basic time unit (one opportunity to TX, RX, ACK, contend or sleep). Slotframe = repeating set of timeslots. Slot offset = a cell’s position in the slotframe. §5.2
Dedicated vs shared cell: one benefit and one cost of each.
Dedicated: predictable, contention-free; wasted when nothing is queued. Shared: flexible for joining, control and bursts; reintroduces collisions and backoff. §5.2
Communication graph vs conflict graph: what are the vertices of each?
Communication graph: nodes (edges = usable links). Conflict graph: transmissions (edges = pairs that cannot share a resource). §5.4

Short: lower delay, faster retries, higher activity. Long: more cell positions and sleep, longer waits, slower recovery. Longer is not automatically more efficient. §5.6

  • (ii) Mechanism — RSSI includes interfering energy and says nothing about lost frames; a metal-rich factory adds multipath and 2.4 GHz coexistence (Wi-Fi). §2.3
  • (iii) Measure — noise floor and SNR, PRR in both directions (ACK path), retransmission and missing-ACK counts, Timeline overlaps, channel occupancy.
  • (iv) Trade-off — more TX power costs energy and cannot remove collisions, asymmetry or interference; it can even raise interference for neighbours.
  • (v) Fix — investigate interference, collisions, noise and directional PRR before changing power; then change channel / hop, schedule, or reposition the antenna.

Scenario 5Energy versus emergency response Rec 3e

A battery-powered smoke detector sleeps most of the time. Its wake-up interval is increased from 100 ms to 1,000 ms to conserve energy.

Q: What changes when the device needs to transmit an urgent alarm through three hops?

Model answer
  • (ii) Mechanism — asynchronous rendezvous: each hop waits on average T_w / 2 for the next receiver’s check. §4.7
  • (iii) Numbers — mean waiting component 3 × 50 ms = 150 ms → 3 × 500 ms = 1,500 ms (worst case ≈ 3 s), excluding transmission, processing and retry delays. Receiver idle duty falls 10× (e.g. 5 ms checks: 5 % → 0.5 %).
  • (iv) Trade-off — receiver idle energy decreases, but alarm latency grows tenfold and each sender repeats for longer.
  • (v) Decision — keep the short interval on the alarm path, or use phase lock / a scheduled alarm track; tie T_w to the alarm deadline, not only to battery life.

Scenario 6Reliable packets, unreliable datagrams Rec 3f

Scenario 14A cell stuck under Wi-Fi

A TSCH network uses the 16-channel hopping sequence with a slotframe of 16 slots. One link loses about 60 % of its frames; neighbouring links are fine. A Wi-Fi access point on channel 1 is nearby.

Scenario 17The prefix changed overnight

The border router’s global prefix changes from 2001:db8:100::/64 to 2001:db8:200::/64. Nodes that missed the update keep compressing with context ID 1. Their packets start arriving at the wrong destination or not at all.

Q: Explain the failure and how to prevent it.

Model answer
  • (ii) Mechanism — stateful compression sends “context 1” instead of the 64-bit prefix; sender and receiver must hold the same mapping.
  • (i) Diagnosis — a stale context makes the receiver rebuild the wrong address, so decompression silently produces a different IPv6 address.
  • (iv) Trade-off — stateful compression saves bytes by creating shared state, an operational dependency.

Scenario 19The hidden terminal that would not appear

In the Cooja hidden-terminal lab, a student places A and C 70 units apart with B in the middle (35 each). UDGM transmission range is 50 and interference range is 100. The Timeline shows no overlaps and PRR is 100 %.

Q: Why did the hidden terminal not appear, and how should the topology change?

Model answer
  • (i) Diagnosis — A and C are 70 apart: beyond the 50-unit transmission range but inside the 100-unit interference range. Each still receives the other’s signal energy, so CCA reports busy and the clients serialise. They are not hidden from each other.
  • (ii) Mechanism — in UDGM, radios inside the interference range receive energy from a transmission they cannot decode, which carrier sensing detects. The deck’s troubleshooting slide says the same: if A and C still hear each other, move them farther apart.
  • (v) Fix — increase A–C beyond the interference range (or reduce the interference range) while keeping A–B and C–B within 50, e.g. range 50 / interference 50 with A–B = B–C = 40 and A–C = 80; run longer so transmissions overlap. Lab 4A B4

Q: Explain the partition and the hidden-terminal effect, and propose a deployment fix.
